LingoBar は、PC のシステム音声、マイクの音声、手入力したテキストを、選んだ言語に翻訳します。原文と訳文を一文ずつ見比べて学べます。音声認識で文の一部が得られた時点から翻訳を始め、日本語の振り仮名は対応する漢字の上に後から表示します。通常は最新の訳文を自動で追いかけ、いつでも立ち止まって過去の字幕を読み返せます。

独立したアプリであり、設定、保存した字幕、インストールパッケージはすべて LingoBar 専用です。**現在のアプリ画面は主に簡体字中国語**です。ドキュメントは中国語・英語・日本語で用意していますが、字幕の翻訳先言語は別途選択します。

![LingoBar の展開表示で合成字幕を表示した例](docs/images/expanded.png)

*現在の画面を Linux Chromium で実際にキャプチャした合成例です。翻訳先にフランス語と日本語を選んでいます。Windows 実機で収音した画面ではなく、音声認識・翻訳サービスも呼び出していません。*

## できること

- 20 言語から 1～8 言語を選び、表示順を変更できます。初期設定は中国語・英語・日本語で、選択した言語だけを翻訳します。
- システム音声、マイク、両方の音源に対応します。長い文を話している間も、同じ区間の原文と訳文を更新し続けます。
- 日本語の訳文を先に表示し、同じ翻訳モデルで振り仮名を補います。振り仮名の取得に失敗しても訳文は残ります。
- 展開表示とコンパクトな小窓を切り替えられます。小窓でも原文、選択したすべての言語、文字選択、過去の字幕の閲覧を利用できます。
- 最前面表示、背景の不透明度、文字サイズ、広いドラッグ領域、トレイ、任意のログイン時起動に対応します。保存した字幕は Markdown に書き出せます。

## インストールとダウンロード

| プラットフォーム | 入手方法と要件 |
| --- | --- |
| Windows | Windows 10/11 **x64**。[Draft PR #2](https://github.com/seihn2/lingobar/pull/2) の最新の成功した CI からテスト用 artifact をダウンロードし、展開後に `LingoBar-0.1.5-windows-x64-setup.exe` を実行します。パッケージには `SHA256SUMS.txt` が含まれます。 |
| macOS | Apple Silicon、macOS 14.2 以降。現在は下記のコマンドでソースから `LingoBar.app` を生成します。リポジトリに正式 release のダウンロードはありません。 |

Windows のテストパッケージは**未署名**で、Windows ARM64 にはまだ対応していません。Mac のローカルビルドは ad-hoc 署名で、Apple の公証は受けていません。インストール前に入手元とチェックサムを確認してください。[CI のビルド記録](https://github.com/seihn2/lingobar/actions/workflows/build.yml?query=branch%3Acodex%2Fwindows) は、実機検証の完了を意味しません。

Artifact のダウンロードには GitHub へのログインが必要です。保存期間は 14 日で、期限切れの場合は新しい成功したビルドから取得するか、自分でビルドしてください。**古いコミット `96b0b30` のインストーラーには、待機中に特定のマイクを選択できない問題があります。修正の基準となる `f7a64b8` 以降のコミットに対応した、PR の最新パッケージに置き換えてください。** 更新する前に、トレイ／メニューバーの **退出 LingoBar**（LingoBar を終了）でアプリを終了してから、新版をインストールまたは置き換えてください。このブランチは引き続き draft PR の段階で、未マージ・未デプロイ・正式 release 未公開です。

## 5 ステップで始める

1. アプリを開き、まず **看看示例**（表示例を見る）でレイアウトを確認します。この例は録音せず、サービスも呼び出しません。
2. **设置 → 服务连接**（設定 → サービス接続）で、音声認識と翻訳それぞれの接続先、モデル、API Key を入力し、**保存设置**（設定を保存）を押します。
3. **电脑声音**（システム音声）、**麦克风**（マイク）、**双音源**（両方の音源）から選びます。聴き取りを始める前に、使用するマイクを指定できます。デバイス一覧の取得や更新では録音は始まりません。
4. **设置 → 字幕语言**（設定 → 字幕言語）で言語を選び、表示順を変更します。必要に応じて **日语汉字注音**（日本語の漢字に振り仮名を付ける）を有効にします。
5. **开始聆听**（聴き取りを開始）を押します。過去の字幕を読むにはスクロールまたは文字選択を行い、**回到实时**（リアルタイム表示に戻る）で自動追従を再開します。収音を終えるときは **暂停**（一時停止）を押してください。ウィンドウを隠すだけでは停止しません。

音声認識の初期設定は DashScope 北京リージョンの `qwen-audio-3.1-asr-flash-streaming`、翻訳の初期設定は DeepSeek の `deepseek-flash` です。待ち時間を減らすため、クライアント側で思考モードを無効にしています。2 つのサービスにはそれぞれキーを設定し、各モデルを利用できるアカウントが必要です。**オンラインの音声認識、翻訳、振り仮名生成には API 料金が発生する場合があります。** 遅延や認識できる言語は、ネットワーク、デバイス、選んだモデルによって異なります。

サービスの各設定項目、システム権限、ウィンドウ操作、トラブル対処は、[詳しい使い方ガイド](docs/usage.ja.md)を参照してください。

## 小窓とショートカット

![LingoBar の小窓で合成字幕を表示した例](docs/images/compact.png)

*同じ現行画面で合成字幕を表示した小窓です。実際のウィンドウのドラッグ、各 DPI、音声ハードウェアは、引き続き実機での検証が必要です。*

小窓の上端 20px と、左右および下端の 8px の余白をドラッグして移動できます。本文は選択・スクロール可能です。マウスを重ねるか、キーボードでフォーカスすると操作ボタンが現れます。背景の不透明度は 45～100% で調整でき、文字の不透明度は維持されます。

| 操作 | Windows | macOS |
| --- | --- | --- |
| 翻訳バーの表示／非表示（グローバル） | `Ctrl+Alt+L` | `⌘⌥L` |
| 手入力テキストの送信（入力パネル内） | `Ctrl+Enter` | `⌘ Enter` |
| 聴き取りの開始／一時停止 | 画面またはトレイメニュー | 画面またはメニューバーメニュー |

ショートカットが他のアプリで使われている場合は、トレイ／メニューバーからウィンドウを開けます。閉じるボタンはアプリを非表示にします。終了するにはメニューの **退出 LingoBar**（LingoBar を終了）を選んでください。

## データとプライバシー

- 初回起動時に自動で収音することはなく、ログイン時起動でも聴き取りは自動再開しません。システム音声の収集は音声のみで、画面は取得しません。Windows では WASAPI loopback、Mac では Core Audio を使用します。
- 聴き取りを開始すると、設定した音声認識サービスに暗号化された接続で音声を送信します。認識した原文や手入力したテキストは翻訳サービスに送信します。サービス提供者のデータ取り扱い条件も別途適用されます。
- キーはメインプロセスが Electron の `safeStorage`（Mac のキーチェーン／Windows の DPAPI）で暗号化し、画面には返しません。暗号化が利用できない場合や失敗した場合は保存を拒否し、平文での保存には切り替えません。
- 録音は保存しません。通常の会話は直近約 150 文をメモリ内だけに保持します。明示的に保存した字幕はローカルに最大 1000 文保持でき、Markdown に書き出せます。
- データディレクトリは、Mac が `~/Library/Application Support/LingoBar`、Windows が `%APPDATA%\LingoBar` です。アプリ ID は `com.lingobar.app` です。
- Mac の **导入语音识别密钥**（音声認識キーをインポート）は、明示的にクリックした場合にのみ、固定のローカルキーチェーン項目を読み取ります。Windows ではこの項目を表示せず、呼び出しも拒否します。

<a id="development"></a>
## 開発とビルド

共通プロジェクトには Node.js **22.18 以降**（22 LTS を推奨）と npm を使用します。まずスクリプトを読み、`npm ci` でロックされた依存関係をインストールしてください。

```sh
git clone https://github.com/seihn2/lingobar.git
cd lingobar
git switch codex/windows
npm ci
npm test
npm run typecheck
```

| プラットフォーム | ビルドに必要なもの | パッケージ作成コマンド | 出力 |
| --- | --- | --- | --- |
| macOS | Apple Silicon、macOS 14.2 以降、Xcode Command Line Tools | `npm run package:mac` | `dist/mac-arm64/LingoBar.app` |
| Windows x64 | Windows、CMake 3.24 以降、Visual Studio 2022 の C++ デスクトップ開発ツールと Windows SDK | `npm run package:win` | `dist/LingoBar-0.1.5-windows-x64-setup.exe` |

開発用の起動前に `npm run build:native` を実行します。Windows では `npm run build:icons` も実行し、その後 `npm run dev` で起動します。ネイティブコンポーネントは対象のプラットフォーム上でビルドする必要があります。

| チェック | コマンド |
| --- | --- |
| 本番用ビルドと型チェック | `npm run build` |
| 実際の Electron を使った合成デバイスの権限フロー | `npm run test:media-permissions` |
| Chromium での合成字幕 UI（インストール済みブラウザーが必要） | `npm run test:ui` |
| パッケージ内 Windows helper の合成セルフテスト | `npm run test:windows-native` |
| パッケージ内容、リソース、第三者の権利表記 | `npm run verify:package` |
| Windows インストーラーの SHA-256 | `npm run checksums:win` |

## バージョンと検証範囲

現在のコードのバージョンは **0.1.5** です。機能と修正内容はコミット番号で確認してください。Windows、macOS、Ubuntu の CI で、実際の Electron を使った合成デバイスの権限テストを実行します。このテストは fake UI による自動許可を使用せず、実際のマイク、個人の音声、有料 API にもアクセスしません。

Windows 10/11 実機での収音、デバイスとシステム権限、トレイ／ショートカット、ログイン時起動、一般ユーザーアカウントでのインストール／アンインストール、ネイティブウィンドウのドラッグ、実際の 100%／150%／200% DPI は、**まだ検証していません**。ブラウザーの拡大率による模擬チェックや CI のビルド成功は、これらの代わりにはなりません。今回の Mac CI でも、実際の収音、キーチェーンの確認画面、実サービスを通した一連の動作は再検証していません。

[テストマトリクス](docs/windows-validation.md)、[Windows 移植の説明](docs/windows-port.md)を参照してください。問題を報告する際は、コミット番号、OS、デバイス、表示倍率、再現手順を記載し、キー、個人の字幕、録音を除いてください：[Issues](https://github.com/seihn2/lingobar/issues)。
