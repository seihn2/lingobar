<a id="install"></a>
## 1. 安装与第一次打开

| 平台 | 操作 |
| --- | --- |
| Windows 10/11 x64 | 打开 [main 分支 CI](https://github.com/seihn2/lingobar/actions/workflows/build.yml?query=branch%3Amain)，从成功构建的 **Artifacts** 下载 Windows 测试包。登录 GitHub 后下载 ZIP，解压，核对 `SHA256SUMS.txt`，运行 `LingoBar-0.1.5-windows-x64-setup.exe`，然后从开始菜单打开 LingoBar。 |
| macOS 14.2+ / Apple Silicon | 从 [PR #3](https://github.com/seihn2/lingobar/pull/3) 的成功 CI 下载 **LingoBar-macos-arm64-preview-…**。解开外层 artifact ZIP，按 `SHA256SUMS.txt` 核对内层应用 ZIP 和 `BUILD-MANIFEST.json`，再用 Finder 或 `ditto -x -k app.zip output` 解开应用。运行此预览无需安装 Node／Xcode；仍可[从源码构建](../README.md#development)。 |

Windows 安装包未签名，可能出现系统来源提示；请先核对来源和 SHA-256，再决定是否运行，不需要关闭系统防护。Mac 预览与本地包均为 ad-hoc 签名，未经 Apple 公证；保留系统防护，不移除 quarantine 或重新签名下载包。重新构建后可能需要重新授权。PR #3 预览不含 PR #4 的暂停改动。manifest 区分 PR head 与实际 CI test-merge 构建，CI 不等于实机验收。“看看示例”可离线预览，不调用服务。详见[技术验收清单](macos-offline-validation.md)。

Artifact 保留 **14 天**，不是永久 release 下载。过期后使用新的成功构建或自己构建。Windows 暂不支持 ARM64。旧提交 **`96b0b30`** 的包存在闲置时无法选择具体麦克风的问题，应使用新的成功 CI 构建提供的替代包。修复基线为 `f7a64b8` 及其后续提交。升级前先从托盘／菜单栏选择“退出 LingoBar”，再安装或替换新版。Windows 实现已通过 [PR #2](https://github.com/seihn2/lingobar/pull/2) 合并到 `main`，仍以开发预览分发，尚未发布正式 release。

第一次打开不会自动收音。先点 **看看示例**，可查看合成字幕布局，不调用服务。也可打开 **输入文字翻译**，输入或粘贴一句，再点 **翻译这句** 或使用下方表中的提交快捷键。提交时会调用翻译服务，但不使用麦克风。

<a id="services"></a>
## 2. 配置两项服务

进入 **设置 → 服务连接**。语音识别和字幕翻译是两项独立配置：即使用同一个供应商，也要确认地址、模型和密钥各自匹配。

| 字段 | 默认值／说明 |
| --- | --- |
| 语音识别 API Key | 你的 DashScope 密钥；不要在截图、日志或 Issue 中公开。 |
| 识别模型 | `qwen-audio-3.1-asr-flash-streaming`，默认省略语言提示以自动识别。 |
| 识别服务地址 | 北京区 `wss://dashscope.aliyuncs.com/api-ws/v1/inference`；自定义地址须使用 WSS。 |
| 翻译 API Key | 你的翻译服务密钥；默认 DeepSeek，与识别密钥分别填写。 |
| 翻译模型 | 默认 `deepseek-flash`，客户端关闭思考模式以减少等待。 |
| 翻译服务地址 | 默认 `https://api.deepseek.com`，使用兼容 OpenAI 的聊天接口；须为 HTTPS，本机服务可用 HTTP。 |

自定义 ASR 接口还须兼容本应用实现的 Qwen streaming／realtime 协议；填写 WSS 地址不代表任意语音识别服务都能接入。

点击 **保存设置**。密钥输入框留空会保留原密钥；界面只显示是否已配置，不显示解密后的值。设置保存成功并不证明账户能调用该模型，仍需检查账户权限、余额与网络。

**语音识别、翻译、重新翻译以及日语注音都可能产生 API 费用。** 只翻译所选语言可以减少不需要的请求，但不能保证免费。费用、模型可用性和数据处理规则以服务商为准。参考：[Qwen 实时识别](https://help.aliyun.com/en/model-studio/real-time-speech-recognition-user-guide)、[DeepSeek 接口](https://api-docs.deepseek.com/api/create-chat-completion/)。

Mac 还提供 **导入语音识别密钥**：只有主动点击才读取固定的本机钥匙串项目；它只更新识别配置，不修改翻译服务。Windows 不提供此功能，请手动填写。

<a id="audio"></a>
## 3. 选择声音与授予权限

| 音源 | 采集内容 | 使用建议 |
| --- | --- | --- |
| 电脑声音 | 启动时系统默认输出设备的音频混合流 | 播放需要学习的音频，并确认正确的输出设备。 |
| 麦克风 | 在 **服务连接 → 麦克风** 选择的设备，或系统默认麦克风 | 可在闲置或暂停时选择具体设备。刷新设备只查询列表，不开始录音。 |
| 双音源 | 独立的系统音频与麦克风识别会话 | 建议戴耳机，减少扬声器内容被麦克风重复收录。 |

选择音源后点 **开始聆听**。启动状态不等于已有字幕；还需实际音频、可用账户和服务响应。识别语言范围取决于所选 ASR 模型，并不承诺识别所有语言。

- **Windows 麦克风：** 在“设置 → 隐私和安全性 → 麦克风”开启麦克风访问，并允许桌面应用访问。Windows 10 对应分类名为“隐私”。
- **Windows 系统声音：** 使用 WASAPI loopback，只采音频，不需要屏幕录制权限，也独立于麦克风。受保护内容、独占播放或设备限制可能使声音不可用。
- **Mac：** 按系统提示授予麦克风或系统音频录制权限；相关设置位于“系统设置 → 隐私与安全性”。系统声音使用 Core Audio，不采集画面。具体项目名称可能随系统版本变化。

切换音源前请先暂停；启动或聆听中音源按钮不可切换。保存麦克风设备或服务配置改动时，会暂停当前聆听。默认设备变化、所选麦克风拔出或系统输出失效时，也应确认设备后重新开始；应用不会静默跨到另一台物理设备继续收音。双音源中任一路失败，会结束两路。

点 **暂停** 会结束采集与识别，并保留已识别的未完片段；已经提交的翻译或自动注音可以继续完成；手动重试注音会取消。关闭面板、收起或隐藏窗口不会暂停。退出应用才会彻底结束当前应用进程。

<a id="live"></a>
## 4. 边听边译，不必等长句说完

原文有可用的中途识别片段后，应用就安排翻译。同一语段会随着讲话持续补全，最终识别结果再校正译文；连续更新会合并处理，避免每个字都单独请求。

还在等待新译文时，保留上一版可读译文；显示的原文与该版译文对齐，尚未翻出的后续内容另作提示。不同语段顺序追加，不会因为旧段注音稍晚返回而把视线拉回去。

网络、供应商缓冲和模型推理都会影响等待时间。示例和合成测试不能作为真实翻译速度或准确率的保证。

<a id="languages"></a>
## 5. 字幕语言与日语振假名

进入 **设置 → 字幕语言**：

1. 从 20 种语言中保留 **1–8 种**，默认中文、英文、日语。
2. 用所选语言旁的左右箭头调整顺序。只翻译勾选的语言；第一种语言也用于历史列表的预览。
3. **展开视图显示原文** 只控制展开模式；小窗始终保留原文和全部所选语言。
4. 选中日语后，可开启 **日语汉字注音**。译文先显示，再由同一个翻译模型按语境生成读音，标到对应汉字上方。
5. 保存设置。历史语段缺少新选的语言时，可以按当前组合重新翻译，原有结果保留。

注音不会阻塞译文；失败时不会撤掉日语文字。人名、多音词或特殊表达仍应人工核对。注音是 LLM 结果，不是词典或发音正确性的保证。

日语译文已完成但注音失败时，点击 **重试日语注音**，只为这段补注音，不重新翻译，也不启动录音；暂停后仍可操作。需保持日语和注音选项开启，并已配置可用服务。重试注音仍可能产生 API 费用。取消、切换语言或离开网页会取消待处理的手动注音请求。

<a id="history"></a>
## 6. 自动跟随、回看、收藏与导出

默认跟随**最新已有译文**，不必手动翻页。原文还没有译出时，可继续阅读上一段；当前语段的部分译文一到便更新到同一位置。

- 滚动、拖动滚动条、按阅读方向键或选择文字，会暂停跟随，便于回看和复制。
- 点 **回到实时** 恢复跟随。回看期间新字幕仍会接收，不会被丢弃。
- 点 **历史与收藏** 查看近期语段或学习收藏；选择一段即可回到它的阅读位置。
- 完成的语段可用书签按钮收藏。尚在识别、补全或翻译中的语段暂不能收藏。
- **导出收藏** 将学习收藏导出为 Markdown，包含原文、已有译文和可用的日语读音。导出内容由你自行保管。
- 已收藏句子重译中或重译失败时，仍可导出保留的旧译文。导出期间按钮显示“正在导出…”；结果只显示在历史面板，关闭后重开仍可查看。取消不显示成功，也不会改动收藏；写入失败后可换保存位置重试。
- 语段上的重新翻译按钮按当前目标语言组合调用翻译服务，可能产生额外费用。

### 本地查找

当前源码已包含本地查找。此前的 `main` 预览包不含此功能，请使用本次优化 PR 的成功构建，或从包含此改动的提交自行构建。文档中的功能说明不等于实机验收。

- 在应用内按 `Ctrl+F`（Windows）／`⌘F`（Mac），打开 **历史与收藏** 并聚焦查找框；小窗会先展开。也可从 **历史与收藏** 进入查找。
- 按字面查找本机仍保留的原文、最后一次译文对应的原文和全部已有译文，包括当前未显示的语言。匹配会忽略大小写并做 Unicode 归一化，例如统一全／半角；查找词不会作为正则表达式执行。
- 用 **全部**／**学习收藏** 限定结果。在查找框内按 `Enter`／`Shift+Enter` 循环选中下一个／上一个匹配，点击条目才跳回对应字幕段落。
- 所选语段仍保留且仍匹配时，新到字幕或迟到译文不会把选择移到其他语段，也不会主动改变当前回看位置。按 `Esc` 关闭面板，焦点会回到打开它的控件；紧凑模式展开后原控件已替换时，返回展开视图中的对应入口。设置和文字面板也保留这一返回路径。
- 查找只处理本地已有文字，不新增 API 调用或重新翻译，不保存查找词；退出面板后清空查询。已淘汰的记录，以及退出应用前未收藏的旧会话，不在查找范围内。

普通会话保留在内存中，最近约 150 句；关闭应用后不会恢复。主动收藏保存在本地，上限 1000 句，不是录音文件。


### 桌面学习（本 draft 新增）

紧凑窗的 **留句** 或 `Ctrl/⌘+Alt+S` 一次收藏当前可见完成句，重复操作不会取消收藏，也不打开卡片。展开视图请用句子旁的 **留句**。点击 **笔记** 主动打开冻结详情，选择原文中的连续短语并添加自己的笔记；**会话匣** 整理本地会话，也能查看旧收藏。草稿仅在内存，离开前需保存或明确放弃。新闻使用既有 **输入文字翻译** 主动粘贴。

这些学习动作不新增服务请求；原有识别、翻译、注音仍按服务商计费。此功能限桌面版，不会读取游戏文字、网页或监听剪贴板。详见[学习使用与数据边界](desktop-learning.md)，包括保存失败、短语范围和实机未验证项。


### AI语境解释、学习历史与主动复习（桌面 draft）

在冻结详情加入连续原文短语后，**解释这处用法** 会先显示将发送的短语、冻结单句、一个解释语言及服务/模型。明确点击才调用现有服务并可能计费；它把结果保存在独立的 **学习历史**，取消旧字幕收藏不会删除它。结果恒标 **AI生成，可能不准确**；原形、读音、词性和例句均非权威词典信息，读音对应所选形式还是建议原形也未核实。没有配置时不能解释。

学习历史可分页搜索、收藏、写笔记、删除、导出；**复习收藏** 先回忆再揭示已保存答案，只有 **记起了／没记起** 记录自评，跳过不计，最近一次可撤销。不安排SRS或宣称掌握。查看、收藏、笔记、导出和复习不新增请求；**重新解释** 才会再次调用。取消等待不等于退款；结果尚未保存时只能重试保存，不会重新请求。详见[数据、失败处理与验证边界](dictionary-learning.md)。真实词典/Yomitan导入尚未交付。

**不允许开机启动。** 新旧配置均按关闭处理，不能启用或恢复登录项；启动和保存普通设置不写系统登录项。如需处理旧版本残留，可明确点击 **设置 → 显示与启动 → 移除语伴登录项**。仅移除本应用自身用户项，不更改系统权限；无法确认时显示错误，不自动重试。其他未保存的编辑不会随该操作保存，实际系统残留仍需单独核对。

<a id="privacy"></a>
## 8. 密钥、数据与隐私

| 数据 | 去向与保留方式 |
| --- | --- |
| 麦克风／电脑音频 | 开始聆听后经加密连接发往配置的 ASR 服务；应用不保存录音。 |
| 识别原文／手动文字 | 发往配置的翻译服务，用于所选语言翻译和可选日语注音。 |
| API Key | 主进程通过 Electron `safeStorage` 加密，Mac 使用钥匙串，Windows 使用 DPAPI；不回传给界面。加密不可用或失败时拒绝保存，不能退回明文。 |
| 普通字幕 | 仅在会话内存中保留最近约 150 句。 |
| 学习收藏 | 本地保存，上限 1000 句；可主动导出 Markdown。 |

Windows 数据目录为 `%APPDATA%\LingoBar`，Mac 为 `~/Library/Application Support/LingoBar`。密钥加密依赖当前系统用户；复制配置目录到另一台电脑或系统账户不保证可以解密。

设备列表查询只允许受信主窗口查询音频状态，不代表允许收音；实际 `getUserMedia` 请求仍需主动开始的有效会话。摄像头、不可信页面与子框架请求会被拒绝。系统隐私设置仍可能限制设备名称或访问。

发布截图、日志、Issue 或导出笔记前，请去除密钥、个人原文、字幕和录音。服务商收到的数据受其条款约束。

<a id="troubleshooting"></a>
## 9. 遇到问题时

| 现象 | 先检查 |
| --- | --- |
| 闲置时无法选择麦克风 | 是否误用了旧 `96b0b30` 包；改用新的成功 CI 构建提供的替代包，刷新设备，并检查系统权限。无需先收音来解锁设备列表。 |
| 没有原文字幕 | 音源、实际音频、默认输出或麦克风、OS 权限、ASR 地址／模型／密钥及账户权限。 |
| 原文有了但没有译文 | 翻译服务的独立密钥、地址、模型、账户余额和网络；它不沿用 ASR 密钥。 |
| 只有一路声音或出现重复字幕 | 双音源设置、麦克风权限和当前输出设备；使用耳机减少回声与重复收录。 |
| 切换设备后停止 | 确认设备后重新开始，这是明确结束旧采集会话的处理。 |
| 密钥无法保存／解锁 | 系统加密服务、当前系统账户和钥匙串／DPAPI 状态；必要时重新输入，应用不会改存明文。 |
| 字幕停在旧段落 | 可能正在回看或有文字选择；点“回到实时”。 |
| 译文有了但注音未出现 | 是否选择日语并开启注音；稍候或重新翻译，注音失败不影响译文。 |
| 窗口找不到／快捷键无效 | 从托盘或菜单栏打开；检查 `Ctrl+Alt+L`／`⌘⌥L` 是否被其他应用占用。 |
| 安装包下载失效 | Artifact 只有 14 天保留期，去 main 分支成功 CI 获取新包，或按 README 自行构建。 |
