<a id="install"></a>
## 1. インストールと初回起動

| プラットフォーム | 手順 |
| --- | --- |
| Windows 10/11 x64 | [main ブランチの CI](https://github.com/seihn2/lingobar/actions/workflows/build.yml?query=branch%3Amain) を開き、成功したビルドの **Artifacts** から Windows テストパッケージを取得します。GitHub にログインして ZIP をダウンロード・展開し、`SHA256SUMS.txt` を確認してから `LingoBar-0.1.5-windows-x64-setup.exe` を実行します。その後、スタートメニューから LingoBar を開きます。 |
| macOS 14.2 以降 / Apple Silicon | [PR #3](https://github.com/seihn2/lingobar/pull/3) の成功した CI から **LingoBar-macos-arm64-preview-…** を取得します。外側の artifact ZIP を展開し、内側のアプリ ZIP と `BUILD-MANIFEST.json` を `SHA256SUMS.txt` で照合してから、Finder または `ditto -x -k app.zip output` でアプリを展開します。実行に Node／Xcode のインストールは不要です。[ソースからのビルド](../README.ja.md#development)も利用できます。 |

Windows インストーラーは未署名のため、入手元に関するシステムの警告が出る場合があります。まず入手元と SHA-256 を確認し、実行するか判断してください。システムの保護機能を無効にする必要はありません。Mac のプレビューとローカルビルドは ad-hoc 署名で Apple 未公証です。保護機能を有効に保ち、quarantine の削除やダウンロードしたアプリの再署名は行いません。再ビルド後に権限の再許可が必要になる場合があります。PR #3 のプレビューに PR #4 の一時停止の変更は含まれません。manifest には PR head と実際の CI test-merge ビルドを区別して記録します。CI は実機検証ではありません。**看看示例** はサービスを呼ばずにオフラインで表示例を確認できます。[技術検証チェックリスト](macos-offline-validation.md)も参照してください。

Artifact の保存期間は **14 日**であり、恒久的な release ダウンロードではありません。期限切れの場合は、新しい成功したビルドを使うか、自分でビルドしてください。Windows ARM64 にはまだ対応していません。古いコミット **`96b0b30`** のパッケージには、待機中に特定のマイクを選べない問題があります。修正の基準となる **`f7a64b8` 以降のコミット**に対応した、新しい成功した CI ビルドのパッケージに置き換えてください。更新前に、トレイ／メニューバーの **退出 LingoBar**（LingoBar を終了）でアプリを終了してから、新版をインストールまたは置き換えます。Windows 実装は [PR #2](https://github.com/seihn2/lingobar/pull/2) を通じて `main` にマージ済みです。引き続き開発プレビューとして配布しており、正式 release はまだありません。

初回起動時に自動で収音することはありません。まず **看看示例**（表示例を見る）を押すと、サービスを呼び出さずに合成字幕のレイアウトを確認できます。翻訳設定を確かめるには、**输入文字翻译**（テキストを入力して翻訳）を開き、一文を入力または貼り付けて **翻译这句**（この文を翻訳）を押します。下のショートカット表にある Windows の `Ctrl+Enter`／Mac の `⌘ Enter` でも送信できます。送信した時点で翻訳サービスを呼び出し、マイクにはアクセスしません。

<a id="services"></a>
## 2. 2 つのサービスを設定する

**设置 → 服务连接**（設定 → サービス接続）を開きます。音声認識と字幕翻訳は独立した 2 つの設定です。同じ提供者を使う場合も、それぞれの接続先、モデル、キーの組み合わせを確認してください。

| 項目 | 初期値／説明 |
| --- | --- |
| 语音识别 API Key（音声認識 API Key） | 自分の DashScope キー。スクリーンショット、ログ、Issue で公開しないでください。 |
| 识别模型（認識モデル） | `qwen-audio-3.1-asr-flash-streaming`。初期設定では言語ヒントを省略し、自動認識を使用します。 |
| 识别服务地址（音声認識の接続先） | 北京リージョンの `wss://dashscope.aliyuncs.com/api-ws/v1/inference`。カスタム接続先も WSS が必要です。 |
| 翻译 API Key（翻訳 API Key） | 自分の翻訳サービスのキー。初期設定は DeepSeek で、音声認識のキーとは別に入力します。 |
| 翻译模型（翻訳モデル） | 初期値は `deepseek-flash`。待ち時間を減らすため、クライアント側で思考モードを無効にしています。 |
| 翻译服务地址（翻訳の接続先） | 初期値は `https://api.deepseek.com`。OpenAI 互換のチャット API を使用します。HTTPS が必要ですが、ローカルサービスには HTTP を使用できます。 |

音声認識の接続先を変更する場合は、このアプリが実装している Qwen streaming／realtime プロトコルに対応したサービスが必要です。WSS を使っているだけで、任意の音声認識サービスをそのまま利用できるわけではありません。

**保存设置**（設定を保存）を押します。キーの入力欄を空のままにすると、既存のキーを保持します。画面には設定済みかどうかだけを表示し、復号した値は表示しません。設定が保存できても、そのアカウントでモデルを呼び出せることまでは確認できません。利用権限、残高、ネットワークも確認してください。

**音声認識、翻訳、再翻訳、日本語の振り仮名生成には、いずれも API 料金が発生する場合があります。** 選択した言語だけを翻訳することで不要なリクエストを減らせますが、無料になる保証はありません。料金、モデルの利用可否、データ取り扱い規則はサービス提供者の条件に従います。参考：[Qwen リアルタイム音声認識](https://help.aliyun.com/en/model-studio/real-time-speech-recognition-user-guide)、[DeepSeek API](https://api-docs.deepseek.com/api/create-chat-completion/)。

Mac には **导入语音识别密钥**（音声認識キーをインポート）もあります。明示的にクリックした場合にのみ、固定のローカルキーチェーン項目を読み取ります。更新するのは音声認識の設定だけで、翻訳サービスは変更しません。Windows にはこの機能はありません。手動で入力してください。

<a id="audio"></a>
## 3. 音源を選び、権限を許可する

| 音源 | 収集する内容 | 使い方の目安 |
| --- | --- | --- |
| 电脑声音（システム音声） | 聴き取り開始時のシステム既定の出力デバイスでミックスされた音声 | 学習したい音声を再生し、正しい出力デバイスを選んでいることを確認します。 |
| 麦克风（マイク） | **服务连接 → 麦克风**（サービス接続 → マイク）で選んだデバイス、またはシステム既定のマイク | 待機中や一時停止中に、使用するデバイスを指定できます。一覧の更新はデバイスを問い合わせるだけで、録音を始めません。 |
| 双音源（両方の音源） | システム音声とマイクの、独立した音声認識セッション | スピーカーの内容がマイクにも入って重複するのを減らすため、ヘッドホンの使用を勧めます。 |

音源を選び、**开始聆听**（聴き取りを開始）を押します。起動中という表示だけでは、字幕が届いていることを意味しません。実際の音声、利用可能なアカウント、サービスからの応答も必要です。認識できる言語は選んだ ASR モデルによって異なり、すべての言語の認識を保証するものではありません。

- **Windows のマイク：** 「設定 → プライバシーとセキュリティ → マイク」でマイクへのアクセスを有効にし、デスクトップアプリのアクセスも許可してください。Windows 10 では「プライバシー」という分類名です。
- **Windows のシステム音声：** WASAPI loopback で音声だけを取得します。画面録画の権限は不要で、マイクとは独立しています。保護されたコンテンツ、排他モードでの再生、デバイス側の制限により、音声を取得できない場合があります。
- **Mac：** システムの案内に従って、マイクまたはシステム音声収録の権限を許可してください。関連設定は「システム設定 → プライバシーとセキュリティ」にあります。システム音声には Core Audio を使用し、画面は取得しません。項目名は OS のバージョンによって異なる場合があります。

起動中・聴き取り中は音源ボタンが無効になるため、音源を切り替えるには、先に **暂停**（一時停止）を押してください。マイクデバイスやサービス設定は、変更を保存した時点で現在の聴き取りを一時停止します。既定のデバイスが変わった場合、選択したマイクが抜かれた場合、システム音声の出力が無効になった場合も、デバイスを確認してから再開してください。通知せずに別の物理デバイスへ切り替えて収音を続けることはありません。両方の音源を使っているときに片方でエラーが起きた場合は、両方のセッションを終了します。

**暂停**（一時停止）を押すと、収音と音声認識を終了し、認識済みの未完の区間を保持します。すでに送信した翻訳や振り仮名生成は、完了まで続く場合があります。パネルを閉じたり、ウィンドウを小窓にしたり、非表示にしたりするだけでは停止しません。アプリのプロセスを完全に終了するには、アプリを終了してください。

<a id="live"></a>
## 4. 長い文が終わる前から、聞きながら翻訳する

利用可能な途中の認識結果が得られると、アプリが翻訳を予定します。同じ区間を発話に合わせて補い続け、最終の認識結果で訳文を修正します。連続する更新はまとめて処理し、一文字ごとに個別のリクエストを送ることを避けます。

新しい訳文を待っている間は、前の読み取れる訳文を残します。表示する原文はその版の訳文に合わせ、まだ翻訳されていない続きは別に示します。異なる区間は順に追加され、古い区間の振り仮名が遅れて返ってきても、表示位置がそちらへ引き戻されることはありません。

待ち時間はネットワーク、サービス提供者側のバッファリング、モデルの推論にも左右されます。表示例や合成テストは、実際の翻訳速度や精度を保証するものではありません。

<a id="languages"></a>
## 5. 字幕言語と日本語の振り仮名

**设置 → 字幕语言**（設定 → 字幕言語）を開きます。

1. 20 言語から **1～8 言語**を選びます。初期設定は中国語・英語・日本語です。
2. 選択した言語の横にある左右の矢印で、表示順を変更します。選んだ言語だけを翻訳します。最初の言語は、履歴一覧のプレビューにも使用します。
3. **展开视图显示原文**（展開表示で原文を表示）は、展開モードだけに適用されます。小窓では常に原文と選択したすべての言語を表示します。
4. 日本語を選ぶと、**日语汉字注音**（日本語の漢字に振り仮名を付ける）を有効にできます。訳文を先に表示し、同じ翻訳モデルが文脈に沿った読みを生成して、対応する漢字の上に表示します。
5. 設定を保存します。過去の区間に新たに選んだ言語の訳文がない場合は、現在の言語の組み合わせで再翻訳できます。既存の結果は保持します。

振り仮名の生成が訳文の表示を妨げることはなく、失敗しても日本語の本文は消えません。人名、複数の読みがある語、特殊な表現などは自分で確認してください。振り仮名は LLM の生成結果であり、辞書や発音の正しさを保証するものではありません。

<a id="history"></a>
## 6. 自動追従、読み返し、保存と書き出し

通常は**最新の表示可能な訳文**に自動で追従するため、手動でページを送る必要はありません。新しい原文がまだ翻訳されていない間は前の区間を読み続けられ、現在の区間の途中訳が届くと同じ場所を更新します。

- スクロール、スクロールバーのドラッグ、読み進めるための方向キー、文字選択で追従を一時停止し、読み返しやコピーができます。
- **回到实时**（リアルタイム表示に戻る）で自動追従を再開します。読み返している間も新しい字幕を受信し、破棄しません。
- **历史与收藏**（履歴と保存）で最近の区間や学習用に保存した字幕を表示します。区間を選ぶと、その位置に戻って読めます。
- 完了した区間は、しおりボタンで保存できます。認識中、更新中、翻訳中の区間はまだ保存できません。
- **导出收藏**（保存した字幕を書き出す）では、原文、取得済みの訳文、利用できる日本語の読みを含む Markdown を出力します。書き出した内容は自分で管理してください。
- 保存した字幕の再翻訳中や再翻訳に失敗した場合も、残っている訳文を書き出せます。処理中はボタンに **正在导出…**（書き出し中…）と表示され、結果は履歴内だけに表示されます。閉じて開き直しても確認できます。キャンセルで成功表示や保存内容の変更はありません。書き込みに失敗したら、保存先を変えて再試行してください。
- 区間ごとの再翻訳ボタンは、現在の翻訳先言語の組み合わせでサービスを呼び出します。追加料金が発生する場合があります。

### ローカル検索

現在のソースにはローカル検索が含まれています。以前の `main` プレビューパッケージには含まれていないため、今回の改善 PR の成功したビルドを使うか、この変更を含むコミットからビルドしてください。機能の説明は実機での検収完了を示しません。

- アプリ内で Windows は `Ctrl+F`、Mac は `⌘F` を押すと、**历史与收藏**（履歴と保存）が開き、検索欄にフォーカスします。小窓の場合は先に展開します。同パネルから直接検索することもできます。
- ローカルに保持中の原文、最後の訳文に対応する原文、取得済みのすべての訳文を文字どおりに検索します。現在非表示の言語も対象です。大文字・小文字を区別せず、全角・半角などの Unicode 表現を正規化します。検索語を正規表現として実行することはありません。
- **全部**（すべて）／**学习收藏**（学習用の保存字幕）で絞り込めます。検索欄内で `Enter`／`Shift+Enter` を押すと、次／前の一致項目を循環して選択します。項目をクリックすると、対応する字幕区間に戻ります。
- 選択中の区間が保持され、一致したままであれば、新しい字幕や遅れて届いた訳文によって別の区間へ選択が移ったり、読んでいる位置が勝手に変わったりしません。`Esc` でパネルを閉じると、開いた操作部品にフォーカスを戻します。小窓から展開して元の部品が置き換わった場合は、展開表示の対応する入口に戻ります。設定とテキスト入力パネルも同様です。
- 検索はローカルの取得済みテキストだけを処理し、追加の API 呼び出しや再翻訳は行いません。検索語は保存せず、パネルを閉じると消去します。保持対象から外れた履歴や、アプリ終了前に保存しなかった過去の会話は検索できません。

通常の会話は直近約 150 文をメモリに保持するだけで、アプリを終了すると復元しません。明示的に保存した字幕はローカルに最大 1000 文保持します。録音ファイルではありません。

## 7. 小窓、ドラッグ、透明度とショートカット

![展開表示の合成例](images/expanded.png)

![小窓の合成例](images/compact.png)

*どちらも現在の LingoBar の画面を Linux Chromium で実際にキャプチャしたものです。原文とフランス語／日本語の訳文は合成データで、録音やサービスの呼び出しは行っていません。Windows のネイティブウィンドウや、実機の DPI の検証結果ではありません。*

右上の **收起翻译条／展开翻译条**（翻訳バーを折りたたむ／展開する）で 2 つの表示を切り替え、読んでいる区間を保持します。小窓は上端全幅の **20px**、左右と下端の **8px** の余白をドラッグして移動できます。本文、ボタン、スクロールバーは読むため・操作するための領域であり、ドラッグ領域ではありません。

小窓は通常、字幕だけを表示します。マウスを重ねるかキーボードでフォーカスすると操作ボタンが現れ、長い内容はスクロールできます。マウスを重ねた状態で背景の不透明度を **45～100%** に調整でき、操作を終えると自動保存します。文字の不透明度は維持されます。文字サイズとログイン時起動は **设置 → 显示与启动**（設定 → 表示と起動）で変更します。最前面表示はメインウィンドウで直接切り替えられ、Mac では複数のデスクトップでの表示にも対応します。

| 操作 | Windows | Mac |
| --- | --- | --- |
| 翻訳バーの表示／非表示（グローバル） | `Ctrl+Alt+L` | `⌘⌥L` |
| テキスト入力パネルで送信 | `Ctrl+Enter` | `⌘ Enter` |
| ローカル履歴検索を開く（この機能を含むビルドが必要） | `Ctrl+F` | `⌘F` |
| 検索欄内で次／前の一致項目を選ぶ | `Enter`／`Shift+Enter` | `Enter`／`Shift+Enter` |
| 現在のパネルを閉じる | `Esc` | `Esc` |
| 聴き取りの開始／一時停止 | 画面またはトレイメニュー | 画面またはメニューバーメニュー |

閉じるボタンは、アプリをトレイ（Windows）またはメニューバー（Mac）に隠します。アイコンをクリックすると再表示できます。ショートカットが他のアプリで使われている場合は、このメニューからウィンドウを開いてください。終了するには **退出 LingoBar**（LingoBar を終了）を選びます。ログイン時起動を有効にしても、自動で収音はしません。

<a id="privacy"></a>
## 8. キー、データとプライバシー

| データ | 送信先と保持方法 |
| --- | --- |
| マイク／システム音声 | 聴き取りを開始すると、設定した ASR サービスに暗号化された接続で送信します。アプリは録音を保存しません。 |
| 認識した原文／手入力したテキスト | 設定した翻訳サービスに送信し、選択した言語への翻訳と、任意の日本語振り仮名生成に使用します。 |
| API Key | メインプロセスが Electron の `safeStorage` で暗号化します。Mac はキーチェーン、Windows は DPAPI を使用し、画面には返しません。暗号化が使えない場合や失敗した場合は保存を拒否し、平文には切り替えません。 |
| 通常の字幕 | セッションのメモリ内だけに、直近約 150 文を保持します。 |
| 学習用に保存した字幕 | ローカルに最大 1000 文保持し、明示的な操作で Markdown に書き出せます。 |

データディレクトリは Windows が `%APPDATA%\LingoBar`、Mac が `~/Library/Application Support/LingoBar` です。キーの暗号化は現在の OS ユーザーに依存するため、設定ディレクトリを別の PC やユーザーアカウントにコピーしても、復号できるとは限りません。

デバイス一覧の問い合わせは、信頼されたメインウィンドウが音声の状態を調べる場合に限って許可されます。この許可は収音の許可を意味しません。実際の `getUserMedia` リクエストには、ユーザーが開始した有効なセッションが必要です。カメラ、信頼されていないページ、子フレームからのリクエストは拒否します。システムのプライバシー設定により、デバイス名やアクセスが制限される場合もあります。

スクリーンショット、ログ、Issue、書き出したノートを公開する前に、キー、個人の原文・字幕・録音を取り除いてください。サービス提供者が受け取るデータには、その提供者の規約が適用されます。

<a id="troubleshooting"></a>
## 9. 困ったときは

| 症状 | 最初に確認すること |
| --- | --- |
| 待機中にマイクを選べない | 古い `96b0b30` のパッケージを使っていないか確認します。新しい成功した CI ビルドの修正版に置き換え、デバイス一覧を更新し、システム権限を確認してください。一覧を使えるようにするために、先に収音を始める必要はありません。 |
| 原文の字幕が出ない | 音源、実際に音が流れているか、既定の出力またはマイク、OS 権限、ASR の接続先／モデル／キー、アカウントの利用権限を確認します。 |
| 原文はあるが訳文が出ない | 翻訳サービス専用のキー、接続先、モデル、残高、ネットワークを確認します。ASR のキーは自動では引き継がれません。 |
| 片方の音源しか入らない／字幕が重複する | 両方の音源を使う設定、マイク権限、現在の出力デバイスを確認します。ヘッドホンで反響と重複収録を減らせます。 |
| デバイスを切り替えると停止する | デバイスを確認してから再開してください。古い収音セッションを明示的に終了する動作です。 |
| キーを保存／復号できない | システムの暗号化サービス、現在の OS アカウント、キーチェーン／DPAPI の状態を確認します。必要に応じて再入力してください。アプリが平文保存に切り替えることはありません。 |
| 字幕が古い区間で止まっている | 読み返し中、または文字選択中の可能性があります。**回到实时**（リアルタイム表示に戻る）を押してください。 |
| 訳文はあるが振り仮名が出ない | 日本語を選び、振り仮名を有効にしているか確認します。少し待つか再翻訳してください。振り仮名の取得に失敗しても訳文は残ります。 |
| ウィンドウが見つからない／ショートカットが効かない | トレイまたはメニューバーから開きます。`Ctrl+Alt+L`／`⌘⌥L` が他のアプリで使われていないか確認します。 |
| インストーラーをダウンロードできなくなった | Artifact の保存期間は 14 日です。main ブランチの成功した CI から新しいパッケージを取得するか、README に従って自分でビルドしてください。 |

## 10. バージョン、テストと問題の報告

修正の確認には、0.1.5 というバージョン番号だけでなく、インストーラーに対応する**コミット番号**を使ってください。現在のテストパッケージ、チェックサム、ビルド結果は [main ブランチの CI](https://github.com/seihn2/lingobar/actions/workflows/build.yml?query=branch%3Amain) にあります。[PR #2](https://github.com/seihn2/lingobar/pull/2) には、それ以前に検証したテストパッケージの元のコミットとチェックサムの記録を残しています。詳しい項目は[テストマトリクス](windows-validation.md)で確認できます。

自動テストでは、主要な状態遷移、途中の翻訳、履歴の追従、振り仮名の対応、権限と IPC、helper のライフサイクル、暗号化の失敗、パッケージ内リソースを検証しています。Windows、macOS、Ubuntu の CI で実行する実際の Electron のテストには 2 つの合成デバイスを使い、fake UI による自動許可は使用しません。ウィンドウのスクリーンショットと 100%／150%／200% の拡大率チェックも、合成データを使ったものです。

**Windows 10/11 実機での検証は、まだ完了していません。** 対象は、実際のシステム音声／マイク／両方の音源、システムのプライバシー権限、デバイスとドライバー、トレイとショートカット、ログイン時起動、一般ユーザーでのインストール／アンインストール、ネイティブウィンドウのドラッグ、実際の DPI とマルチディスプレイです。今回の Mac CI でも、実際の収音、キーチェーンの確認画面、実際の ASR／翻訳サービスは再検証していません。有料 API を呼び出すテストは行っていません。CI や合成テストの結果は、これらの検証の代わりにはなりません。

報告時には、コミット番号、OS バージョン、デバイス、表示倍率、音源、再現手順、期待した動作と実際の動作を記載してください：[Issue を報告する](https://github.com/seihn2/lingobar/issues)。キーや個人の内容を添付しないでください。プロジェクトは [CC BY-NC 4.0](../LICENSE) で公開し、第三者の出典は [NOTICE](../NOTICE.md) に記載しています。
