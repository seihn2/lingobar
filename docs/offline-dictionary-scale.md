# 八语言实用规模离线词库

后续[来源读音字段适配](offline-dictionary-readings.md)补齐 `hangeul`／`zh_pron` 及原标签；此页记录的完整八包未重新构建，不会自动获得该补充。

本批在八语共同引擎上，完成英语、日语、韩语、法语、德语、西班牙语、俄语和中文的 **19 个独立来源包**：使用官方单语言／语言标签 JSONL 导出的完整文件，经文字投影构建 SQLite，并接入既有选词、来源义项收藏、历史、导出及主动复习。英语和日语各有英语释义来源；八种语言都有真实中文释义来源，查询缺少中文时明确显示已安装来源的英语／原语言。AI 解释仍由用户另行主动调用。

**完整官方导出不等于收录所有词汇，中文释义包也不等于全词汇中文覆盖。** 各包来源、词头约定及义项有重叠，不跨来源合并。这里记录实际构建和云端验证；不表示已合并 main、发布正式版或完成 Mac/Windows 实机验收。

## 安装和使用

先由用户**暂停音频**，再进入桌面应用 **学习历史 → 管理语言包 → 导入语言包**，选择解压目录中的 `manifest.json`，使旁边的 `entries.sqlite` 保持原样。导入不会自动停止正在运行的音频；音频活跃时会提示先暂停。按需导入、启停、更新或卸载单个来源，不必一次安装全部包。

在 **离线查词** 输入原句、选择原文语言代码、选择连续原文短语，优先释义语言填 `zh`；也可从已有冻结字幕详情查询。界面按来源显示候选和义项，由用户明确选择收藏。缺少中文时显示来源的实际释义语言，不做英语中转或模型补全。更新、禁用或卸载词库不改变已保存的来源／义项快照；查看、笔记、导出和复习不联网。

语言包是数据，不是应用更新。本批完整英语和两个中文来源使用 manifest **schemaVersion 2**，标识真实词条可能超过旧版 100 义项上限；当前运行时上限为 256，SQLite `user_version` 仍为 1。新应用兼容 manifest 1/2，旧 `f1fabe2`／`348fbc3` 客户端拒绝 manifest 2。学习快照与导出也保留版本 2，降级后的旧客户端可能无法读取这些新离线条目或进入只读状态；不能宣称完全双向兼容。旧 `saved.json`、旧 AI 条目格式保持。

## 来源、投影和许可

输入均为官方 Kaikki 预提取 JSONL，不爬网页、不运行下载的提取器：

- English Wiktionary 的英语／日语导出：提取于 2026-10-25，原 dump 为 enwiktionary 2026-10-01。
- Chinese Wiktionary 的日语两个标签页：页面提取日期为 2026-10-27，原 dump 为 zhwiktionary 2026-10-01；HTTP Last-Modified 为 2026-10-29。
- 其余本批中文释义标签页：页面提取日期为 2026-10-29，原 dump 为 zhwiktionary 2026-10-01，文件 Last-Modified 为 2026-10-29。每个实际 URL 与日期独立记录，不由英语源日期推定。

这些单语言导出被官方标记为 postprocessed/deprecated；这里固定其实际快照，不冒称未经后处理的 bulk raw dump。可复现流程见[文字投影和构建](kaikki-text-preparation.md)，原日语三源的单独元数据仍保留于 [offline-sources](offline-sources/)，19 源的完整紧凑记录见[清单](validation/offline-multilingual-inventory.json)。

**词库文字数据独立采用 CC BY-SA 4.0，不是应用的 CC BY-NC 4.0，也不是提取程序的 MIT 许可。** 署名归相应 Wiktionary 贡献者及 Kaikki/Wiktextract 提取发布者 Tatu Ylonen 与贡献者。各包 manifest 和学习快照／导出保留具体来源、版本、许可链接与署名。[英语版版权规则](https://en.wiktionary.org/wiki/Wiktionary:Copyrights)、[中文版版权规则](https://zh.wiktionary.org/wiki/Wiktionary:著作权)、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。

投影删除**全部例句／引文、媒体／音频 URL、词源和无关字段**，避免将第三方引文或媒体误按词库文字许可分发。保留词头、语言、词性、来源词形及标签、书面读音、释义与词形关联；不生成缺失读音、释义或例句，不规范化原始正文。词形投影保留来源数据，查询索引排除计数词、辅助动词、表格标签和未填模板等非词形项目。转换与索引独立实现，未复制 Yomitan 或提取器源码。

构建器逐行读取 JSONL 或 `.jsonl.gz`，使用现有 Node/Electron 内建 SQLite。原始文件、投影和数据库不进入 Git。`BUILD-REPORT.json` 记录输入 bytes/hash、实际记录、无词汇内容跳过量和输出数量。`no-gloss`／`empty-gloss` 明确标记不被标签文字伪装成 raw-gloss 释义；合法真实原文、义项没有为通过测试而截断。源中的 225／137／138 义项记录分别由 `yì`、`城關`、`draw` 的最终义项保存／导出／重载／复习检查覆盖。

已知韩语 `갔다`／`먹어요`／`읽었다`／`좋아요` 未命中；其他语言的未命中与字面词头差异保留于结果，未通过更换选词掩盖。中文与日语存在来源异体／读音词头差异，不能据简单字符串判断语义正确率。当前基础是精确、NFC 及来源记录的词形／单跳关联；未承诺通用去活用或递归词形链。源中空白标点条目可按其明确 canonical `] [` 查询，纯空白查询仍拒绝。

报告中的 `chineseSenseShare` 仅为已安装包中声明中文释义的记录比例，来源重叠且义项未跨语言对齐，**不是词汇中文覆盖率或译文质量**。多来源分别收藏、导出、回忆／揭示／自评、卸载后快照仍存在的补验不加入主病例分母。225／137／138 义项的事后边界检查也不增加覆盖率分母。
