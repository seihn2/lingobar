# Eight-language dictionary samples and reproducible builds

The first offline batch uses one common engine and real small samples for
English, Japanese, Korean, French, German, Spanish, Russian and Chinese. It
does not ship eight complete dictionaries or a hosted language-pack catalogue.
The current delivery is **local import of built packages**. No online download,
model, API key or automatic translation is needed to build/query these samples.

## Source and license

The sample records were fetched on 2026-10-30 from the official per-word JSONL
downloads linked by [Kaikki.org](https://kaikki.org/index.html). Their pages
identify extraction on 2026-10-25, the English Wiktionary dump dated 2026-10-01,
Wiktextract revision `f9fe161` and wikitextprocessor revision `6f96ddf`.
Each HTTP response was bounded to 2MiB; eighteen actual responses were obtained
successfully, without downloading a full language or the combined 24.8GB dump.
The largest response was 262332 bytes.

The exact response URLs, Last-Modified values, response SHA256, original line
SHA256 and projected-line SHA256 are recorded in
[SOURCES.json](../test/fixtures/offline-dictionaries/SOURCES.json). The committed
34 JSONL rows are explicitly **field projections** of those real responses,
not synthetic lexical entries and not untouched raw-dump lines. They retain
headwords, language, POS, recorded forms, written pronunciations and sense
glosses/tags/form-of links. All examples/quotations, media/audio URLs, etymology
and unrelated fields were removed from these small redistributable fixtures.
Missing examples are left absent, never generated by the importer or an LLM.

Dictionary text is credited to Wiktionary contributors, extracted/published by

## Reproduce the local packages and measurements

With the repository's existing development dependencies and Node22 or newer:

```sh
node scripts/build-dictionary-samples.cjs
```

This command reads committed samples only and writes
`dist/offline-dictionaries/<packId>/manifest.json` plus `entries.sqlite` for all
eight languages, alongside `report.json`, source/license records and
`SHA256SUMS.txt`. The output directory must be new; use `--output new-directory`
for another run. It does not silently replace an existing package directory.
The report records its actual Node/platform/architecture and timings. SQLite
files are runtime data, not native executable dependencies.

The builder accepts a separate local JSONL and explicit source/license metadata:

```sh
node scripts/build-dictionary-pack.cjs --input source.jsonl --output new-pack-dir --metadata source-metadata.json
```

Metadata examples are the `*.metadata.json` files beside the samples. Set the
actual source/definition languages, revision, attribution and data license for
each new dataset; changing the language code does not translate definitions.
Do not copy the sample's license or extraction date to unrelated data.

## Real-data functional cases

The development lemma was used to inspect extraction shape. The second lemma
and selected recorded form are held-out **functional cases**, recorded before
the production-engine run in
[evaluation.json](../test/fixtures/offline-dictionaries/evaluation.json). Their
sentences are synthetic public examples used only to exercise contiguous
selection; they are not user captions or dictionary quotations.

| Source language | Development lemma | Held-out lemma | Recorded selected form → expected candidate |
| --- | --- | --- | --- |
| English | cat | book | books → book |
| Japanese | 猫 | 食べる | 食べた → 食べる |
| Korean | 고양이 | 먹다 | 먹었어요 → 먹다 |
| French | chat | manger | mangeons → manger |
| German | Katze | gehen | ging → gehen |
| Spanish | gato | hablar | hablamos → hablar |
| Russian | кошка | читать | чита́ю → читать |
| Chinese | 貓 | 學習 | 学习 → 學習 |

The first cloud Linux/Node24.19.0 run passed all 24 candidate checks through the
actual `OfflinePacks` module: 32 indexed entries and 146 senses across eight
packages. Source rows with no actual glosses were not presented as definitions.
Per-language entries/senses were en9/67, ja4/6, ko2/8, fr4/7, de2/16, es4/14,
ru2/14 and zh5/14. These counts are not vocabulary coverage or linguistic
accuracy. The report includes candidate IDs/match paths, manifest hashes, pack
bytes, build/install/cold-query time and 100 warm lookups per language.

Real records also revealed metadata inside `forms`: Korean counters, German
auxiliary verbs and table/template/class markers are not inflected forms of the
headword. A follow-up real-data run additionally checked six explicit negatives
(`no-table-tags`, `마리`, `avoir + past participle`, `sein`, `es-conj`, `ru-conj`).
They no longer appear as aliases for the sampled lexical entries. Source forms
remain available for provenance display; this filter does not globally ban
those strings from being legitimate independent dictionary headwords.
The final eight SQLite databases plus their manifests total **561026 bytes**;
source/license records, the evaluation/report and checksum list are additional.
The final cloud run's per-language warm-query p95 values ranged from 0.295 to
5.183ms. These are measured tiny-sample readings under concurrent cloud work,
not a guaranteed latency budget or evidence about full dictionaries/hardware.

All eight samples are extracted from the **English edition** and have English
glosses. The measured Chinese-definition coverage is **0/146 senses**, using
the explicit `glossLanguage` metadata, not script detection or AI translation.
Requesting Chinese definitions shows the fallback to the installed source's
actual gloss language. Chinese word coverage is distinct from Chinese gloss
coverage. The simplified `学习` candidate comes from the recorded `學習` form;
there is no blanket simplified/traditional conversion. Russian `чита́ю` includes
the source's stress mark; unaccented inflection recall is not implied.

Exact/NFC/recorded-form lookup is not a general Japanese deconjugator, Korean
ending analyser, stemmer or semantic word-sense disambiguator. No p95 target,
full-scale load result, real phone/desktop hardware result or learning efficacy
is claimed from these tiny samples. CI report timings must be read as their own
platform run, not substituted for the cloud measurements or native acceptance.

## Deliberate remaining scope

Full raw-language packs and their size/performance, Chinese-language gloss
sources, per-language morphology beyond source-recorded forms, and a hosted
package catalogue remain separate work. JMdict/CC-CEDICT/FreeDict/WikDict can
be considered per source and language pair after checking the specific data
license and value. None is silently bundled or named as the source of these
Kaikki samples. Offline entries and saved source/sense snapshots must retain
their own provenance; an optional AI context explanation remains a separate,
explicit action with its own label and possible provider charge.
