# 本轮真实服务测试：合计最多人民币 1 元（准备中，禁止调用）

本轮预算是**所有供应商合计最多 1 元**，跨日期、重启、浏览器会话都不重置；
不是每天 1 元。目前本轮真实 API 调用及费用均为 0。本文不授权读取或迁移密钥。
已有密钥应从用户确认的安全来源直接复用，不能要求重新发进聊天。

**当前 `executionAllowed:false`。** 已实现离线核价/账本和合成测试，但没有真实
执行器，也没有接管普通 Web 网关的计费。不能通过设置 `WEB_ENABLED=1` 来运行
这一元测试：普通网关的每日请求限额不等于人民币总预算。线上继续关闭真实后端。

## 三个候选最小测试，每项最多一次

全部使用非个人合成数据，不打开用户麦克风。先分项验证供应商握手、文本翻译、
日语注音；不能声称它们等于手机到线上后端的完整实机验收。

| 测试 | 固定输入和输出／次数限制 | 条件成本上界 | 向总预算预留 |
| --- | --- | --- | --- |
| ASR 候选 | 5 秒、16kHz、单声道 PCM16，共 160,000 字节；3.0 streaming 一个连接，一次任务，无重连，不自动翻译/注音 | `5 × 0.00033 = 0.00165` 元 | 0.01 元 |
| 翻译 | 固定合成短句，仅日语；**完整系统提示+用户消息+聊天模板**的输入须先证明不超过 4096 token；`max_tokens:128`、关闭思考，一次 HTTP POST | `(4096×2 + 128×8) ÷ 1,000,000 = 0.009216` 元 | 0.02 元 |
| 注音 | 固定合成原文及「学校」；同样先证明完整输入不超过 4096 token；输出最多 128 token，一次 POST，无格式重试，不重译 | 同上，0.009216 元 | 0.02 元 |
| 合计 | 最多 3 次独立供应商操作 | **0.020082 元，条件成立时** | **0.05 元** |

剩余 0.95 元不自动分配给更多尝试。失败、取消、超时、解析失败、结果未知都占用
原预留，不退款、不自动重试；同一步骤再次申请会被拒绝。返回失败不代表供应商
没有收费。赠额按 0 计算；若实际可用，只可能降低本轮扣款，不能放宽上限或次数。

这些金额是**有前提的上界，不是当前已证明可花的额度**：

- 必须先确认已有安全配置中的供应商、区域、精确模型、端点、人民币结算和计量规则。
  当前不知道是否有 3.0 模型权限；不会为了可算费用擅自切换用户默认 3.1。
- 当前没有实现、运行或证明与实际 flash 模型匹配的完整提示 tokenizer。
  4096 是必须满足的输入上限，**不是测得的 token 数**。不能把字符数、字节数或
  官方给出的平均换算比例当成严格证明。官方说明见

- 默认 3.1 的 ASR 没有已证实的输出 token 上限，不能以 3.0 的秒价替代。
- 原翻译助手当前 `max_tokens:8192`，注音格式错误还可能重试一次。不能直接复用
  普通会话测试来冒充上述一次、128-token 的受限测试。后续真实执行器必须在发送前
  验证完整请求及每项边界，不接浏览器音频或任意输入。
- 若任一成本上界、账户条件或安全来源不能证明，**该项不调用**。不通过一次收费
  请求来“先看看 usage 再决定”，不把余额查询当免费前置步骤。

## 跨日期的单一账本

`scripts/plan-one-rmb-test.cjs` 默认仅打印离线计划，不读环境变量/密钥、不联网、
不写真实账本。导出的 `OneRmbTestLedger` 是未来执行器的记账构件：

- 固定本轮 batch、人民币单位及 1,000,000 微元（1 元）总上限，没有日期重置字段。
- 仅三项固定 attempt ID，预留 0.01/0.02/0.02 元；不能创建任意重试 ID。
- 只有明确的一次性初始化可创建账本；打开时文件缺失、损坏、额度被改或求和错误
  都拒绝，不静默重建成 0。初始化不覆盖已有文件。
- 账本和锁由单进程持有，文件 0600、目录 0700；写入先独占临时文件、fsync，再
  原子替换并 fsync 目录。失败后拒绝后续预留；不把不确定结果退款。
- 不存密钥、JWT、文本、音频或供应商原始响应；不提供退款/重置/自动重试入口。

未来真实执行前须由父任务确定 VM 上**唯一**的私有账本路径并复核初始费用为 0，
所有供应商由同一执行器、同一账本串行预留后调用。不能各容器/各供应商各建一个
1 元账本；不能删除文件、换目录或以新日期开始来恢复额度。崩溃残留锁/临时文件
需先确认没有原进程并保守恢复，不能直接重复未知结果的请求。

账本约束预留，**不会校验供应商实际账单**；普通 Web 网关仍只有独立的每日请求
预算。把此模块放入产物不等于已经给线上网关增加了精确人民币硬停。当前没有
真实发送路径，故不能越过缺失的价格/输入证明或密钥迁移授权。
